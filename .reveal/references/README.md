# Reference Projects

Reference projects are read-only sources of engineering knowledge.

A reference is not another target project and must never be modified by Reveal or execution agents.

References may be used for:

- architecture comparison
- coding-pattern comparison
- technology migration analysis
- testing strategies
- conventions and implementation examples

A target project explicitly declares which references it can use.

## Reference rules

- reference repositories are read-only
- reference knowledge must remain attributable to its source
- differences between target and reference should be recorded as comparative findings
- reference usage does not imply that the target should copy the reference implementation
